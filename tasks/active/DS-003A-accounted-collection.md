- Accounting: logical queries, each Brave/Bing application HTTP request (including fallback), and every page HTTP hop have distinct cumulative counters. Hook admission precedes transport; failed/cancelled admitted attempts stay charged. Hook-origin errors cannot become provider fallback or snippet success. Accounted search uses a dedicated noRedirect transport and rejects search redirect responses; ordinary default behavior is preserved. Page redirect hops keep existing manual validation and require separate admission. Injected fetchers must implement one application request without hidden redirects/retries.

Collection accepts its own host-bound plan, has operation exclusivity, original wall deadline and token-scoped admission; completion/cancel/failure invalidate tokens, and late results cannot debit or append. Successful collection stops at evaluating, not research completed.

Source-slot availability is checked before fetch; retained sources and all title/URL/snippet/page character costs reserve atomically before append. Retained text obeys both character and UTF-8 byte caps. Snippet fallback remains explicitly untrusted and distinguishable from fetched pages.
