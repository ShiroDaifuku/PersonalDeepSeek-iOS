# Integration boundaries

Preserve canonical lineage, existing native protocol/runtime, shared LocalResearchService and API/SSE. Preserve context/images, single current evidence injection and isolated historical citation labels. Raw webpages, tool output, evidence and intermediate claims never directly update Memory/Profile. External data cannot override instructions, request secrets, change permissions or enable mutations.

Research budgets independently bound rounds, queries, unique sources, fetch attempts, retained evidence, synthesis tokens and elapsed wall time. Define actual token accounting/enforcement before model integration.

DS-001 scope: new Foundation state/budget/checkpoint models and tests, engineering control docs and stale AGENTS correction. No Chat routing, prompts, network, SwiftData schema, tools or backend changes.

Human gates: main merge; IPA/upload/release; production deploy/DB migration; real-user-data deletion; irreversible migration; new paid/recurring-cost services; major security, Memory semantics or architecture changes; abandoning substantial completed work.

Normal isolated implementation/review/testing, safe feature push and test-only CI/local integration are authorized. Reinspect triggers before pushing. Current build-ios.yml auto-packages main pushes with matching ios/** or workflow paths; never dispatch it for validation.
